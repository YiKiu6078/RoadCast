# RoadCast 手机副屏

此功能把 RoadCast 收到的导航和音乐数据发送到另一台 Android 手机，由手机重新绘制界面。声音仍从车机播放，不复制 iPhone 认证材料到手机，也不要求手机再次连接 CarPlay。

## 安装与连接

1. 在车机安装 `dist/companion/RoadCast-host.apk`。公开源码默认构建不带运行时认证材料的主程序调试版，真实 iPhone 独立连接需要自行配置外部认证输入。更新原应用时必须保持签名兼容；不要为更新而直接卸载含有重要设置的原应用。
2. 在 Android 7.0+ 手机上安装 `dist/companion/RoadCast-companion.apk`。
3. 两台 Android 设备连接同一个可信 Wi-Fi 网络。不要使用开启了客户端隔离的访客网络。
4. 在车机应用列表打开新增的 **RoadCast 副屏发送**，点 **开始共享**。
5. 首次在手机打开 **RoadCast 手机副屏**，输入发送端显示的 `IP:8766` 和 8 位配对码，点击 **连接**。发送端如列出多个 IP，选择手机可达的 Wi-Fi 地址。配对成功后手机保存车机身份和长期随机凭据，之后打开副屏自动连接，不必重新输入配对码。
6. 正常使用车机 RoadCast 连接 iPhone 并开始导航或音乐播放。连接设置在收到数据后自动折叠，可通过顶部“连接设置”再次展开。
7. 在发送端或常驻通知中点击 **停止共享**，会关闭服务、停止自动恢复并废止当前短配对码，但保留已配对手机的长期凭据。再次开始共享后原手机仍可自动连接。发送端的 **重置配对并停止共享** 会废止所有手机的旧凭据，下次需重新配对。

## 自动连接

首次配对后，车机记住共享开启状态，下次打开主程序 RoadCast 自动恢复共享；手机打开副屏后自动连接已配对的车机。它会优先使用保存的地址，并通过 mDNS/NSD 查找同一车机的新 IP。发送端只广播公开的设备 ID 和端口，配对凭据不会放进发现广播。凭据存储在各自应用私有目录。

手机点击 **断开** 后会关闭自动连接；保留配对的情况下，配对码留空再点 **连接** 即可重新启用。点击 **忘记已配对车机** 可删除手机保存的配对。更换车机时重新输入新车机地址和配对码。

部分车机热点或路由器会过滤 mDNS。如果自动发现失败而地址没有变化，保存的地址仍可连接；地址变化且发现被过滤时，需要手动更新 IP。自动连接不会替设备连接 Wi-Fi，也不会在手机后台强制弹出副屏，或绕过系统强行自启动。车机需打开 RoadCast，手机需打开副屏；局域网权限被撤销时需重新授权。

Android 17+ 首次使用需允许局域网访问，授权后再次点击开始／连接。手机显示期间保持亮屏；退到后台会关闭连接，回到前台后自动重连。发送端通过前台服务继续工作，不会自动开机启动。

## 显示范围

- 导航：转向箭头、距转向点距离、道路、剩余路程和时间（上游有提供时）。未知转向不显示猜测箭头。
- 音乐：歌曲标题、歌手、专辑、封面和暂停状态。
- 歌词：显示音乐 App 通过 CarPlay 标题字段提供的实时文本。未提供歌词时显示歌曲标题，不生成或下载歌词，不提供整首歌词或逐字高亮。
- 第一版不包含地图视频、手机端声音、播放控制或远程触摸。

手机每秒接收完整状态；超过 5 秒没有新状态会清空旧导航并重连。发送端停止、CarPlay 断开时也会清除显示。每条消息包含协议版本、共享会话 ID、序号；接收端拒绝同会话中倒退的序号。

## 网络和配对

这是可信局域网内的明文 WebSocket 连接，不应开放到公网。短配对码只在当前共享服务生命周期中有效，已配对手机使用长期随机凭据重连。错误配对限速，每次只允许一个手机接收。照片封面缩小到最大 256×256 后发送。不会发送 iPhone 认证私钥、证书、音频或控制指令。

如果 iPhone 正通过 Wi-Fi Direct 连接车机，车机是否还能同时访问手机所在局域网取决于硬件和固件。无法互通时，先用 USB CarPlay 加同一 Wi-Fi 验证；也可实测手机连接车机热点。不要假定两个不同的 Wi-Fi 网络天然互通。

## 构建

在仓库根目录运行 `build-companion.cmd`，默认构建不带运行时认证材料的源码调试版，并将两个 APK 导出到 `dist/companion/`。若需要真实 iPhone 独立连接，需自行配置外部认证材料，或执行 `:mobile:assembleStandaloneDebug`。

仅构建手机接收端：`gradlew.bat :companion:assembleDebug`。

主应用：`gradlew.bat :mobile:assembleStandaloneDebug`，仍需按 `docs/BUILD.md` 配置外部认证文件。

## 代码入口

- `common/.../CompanionSenderActivity.kt`：共享入口、局域网权限、地址与配对码。
- `common/.../CompanionSenderService.kt`：前台服务、独立音乐订阅、封面编码、定时同步。
- `common/.../CompanionSocketServer.kt`：WebSocket 配对、限速、单接收端生命周期。
- `common/.../CompanionWire.kt`：版本化完整状态协议，断开时清除旧数据。
- `companion/.../MainActivity.kt`：连接、自动重试、5 秒过期清理、导航与音乐显示。
- `companion-ui/res/`：发送端和接收端共享文案，含英文和简体中文，其余语言回退英文。

测试覆盖实际 TCP/WebSocket 握手与消息收发、未认证连接拒绝、断开时清除导航与歌曲，以及接收端大字体界面截图。截图位于 `companion/build/reports/companion-ui/`。尚需用真实车机、iPhone 和 Android 手机验证网络并发、导航数据、封面和动态歌词；软件构建通过不代表这些实机条件已通过。

依赖：NanoHTTPD WebSocket 2.3.1（BSD-3-Clause）、OkHttp 4.12.0（Apache-2.0），由 Gradle 从 Maven Central 获取。
